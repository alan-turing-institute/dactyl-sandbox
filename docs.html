Pond guide

Dactyl TODO, translated

Dactyl is a TODO app with pond language. The fishy names are decoration; underneath, you are managing tasks, priorities, due dates, and lists.

Back to the pond

Quick vocabulary

Fish
A task or TODO item.
Pond
Your task list.
Shoal
A custom group, project, or theme for related tasks.
Tide
Priority and due-date views, such as overdue or due today.
Ghost net
The archive for completed or moved-away tasks.
Release
Remove a task from the active pond; destructive actions are labelled.

Core flows

Start safely

Sign up or log in to keep tasks synced through the API. Use Log out when you are finished on a shared device.

Add a task

Type the task and choose Add. Use + more options for due dates, GitHub links, priority, shoal, or repeating tasks.

Plan the day

Set due dates and priorities, then use Tide views to find overdue, due-today, scheduled, and low-pressure work.

Group work

Use shoals for projects or themes. Select several tasks, then use Cast net and Move to shoal for bulk changes.

Finish or archive

Complete tasks when they are done. Archive or release only when you mean to remove them from the active pond.

Move data around

Paste to pond imports task lists. Export pond, Copy snapshot, Share visible pond, and Copy stand-up draft help with handoff.

Where to get help in the app

  • Pond tour walks through the main interface.
  • Button help explains each action and marks destructive or external actions.
  • Pond shortcuts lists keyboard commands, including the command palette.
  • Pond health, Daily Catch, and Tide trophies summarize progress without changing tasks.
