What the pond buttons do

A quick map for TODO-app developers swimming through the fishy UI. Opening this guide is read-only; no fish are moved.

➕ Add task
Creates task Adds a new TODO fish with optional due date, GitHub link, priority, and quick-add hints. Requires sign-in.
✓ Complete
Changes task Marks a fish fed/completed. This can be undone from the Archive before permanent release; recurring fish schedule the next occurrence.
× Delete / Release
Destructive Removes a fish. Archive release can be permanent; bulk release shows an undo affordance where supported.
🌊 Filters
View only Full pond, Swimming, Tide mode, Needs Attention, Coming tide, and The reef only change which fish you see. Hidden fish are not modified.
🐟 Stock the pond
Creates demos Adds sample tasks so new users can explore the pond. Your existing fish stay untouched.
🧹 Release demo fish
Deletes demos Removes only demo/sample fish. It never touches your own non-demo tasks.
📋 Paste to pond
Creates tasks Turns pasted bullets or checkbox notes into tasks. Preview first; importing creates real fish in your account.
💾 Haul
Downloads file Saves a backup of your task pond to your device. It does not change task data.
♻️ Restock
Can replace data Loads a backup file. Merge adds imported fish; Replace swaps the current pond after the preview.
📣 Copy pond report / snapshot / stand-up draft
Clipboard Copies text for updates or stand-up notes. The app does not post externally for you.
🔗 Share visible pond
External share Opens your browser/device share sheet for the currently visible pond summary. You choose where it goes.
🎣 Daily Catch
Planning only Suggests a small focus list from due, priority, and feeding signals. Pinning changes only the local planning catch.
🩺 Pond health
View only Shows lightweight diagnostics and can copy a privacy-preserving summary for debugging.
🏆 Tide trophies
View only Displays progress badges. This is read-only and reflects your current task pond.
🔕 Quiet hours
Local setting Configures due-date reminder timing. Notifications are opt-in and stay in the browser.
🫧 Calm Water
Display setting Adjusts visual preferences like reduced celebration intensity and text-first badges. It is stored locally.
🐠 Aquarium view
View only Opens a visual showcase of active fish. It is decorative and does not change task state.
⌨ Pond shortcuts
Help only Lists keyboard commands like search focus, tide filters, reports, and triage. Opening it is read-only.
🧭 Sort the catch
Fast edits Shows one active fish at a time for keyboard completion, send-to-reef, tide level, and due-date changes.
🎯 Feed
Focus state Pins one active task into focus mode. Focus sprints and reports follow this fish until it is fed or cleared.
📝 Details / Edit
Edits task Edit changes core task fields. Details opens private depth notes and scales (checklist) for the selected fish.
🕸 Cast net
Selection mode Lets you select visible fish for batch actions. Hidden tasks stay out of the net until their view is active.
🌊 Release selected
Bulk destructive Releases the fish currently caught in the net. Use the undo message immediately if the wrong fish swim off.
🏷 Move to shoal
Bulk edit Moves selected fish into a custom shoal name, or clears the shoal when left blank. It changes only the caught fish.
